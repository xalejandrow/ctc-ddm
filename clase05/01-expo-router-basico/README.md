# 01 - Expo Router básico

## Qué muestra

- `app/` define las rutas.
- `_layout.tsx` declara un Stack.
- `index.tsx` es la pantalla inicial.
- `router.push('/segunda')` avanza.
- `router.back()` regresa.

## Objetivo de práctica

Crear una tercera pantalla y agregar un botón desde `segunda.tsx` para navegar hacia ella.
