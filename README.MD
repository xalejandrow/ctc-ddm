# Desarrollo para dispositivos Móviles - 2026

Este es un repositorio de ejemplos y documentación para el curso de Desarrollo para dispositivos Móviles de CTC 2026

## Crear un nuevo proyecto React Native en blanco para TypeScript

- npx create-expo-app@latest MiAppBasica --template blank-typescript

## Ejecutar el proyecto

- npx expo start

## Actualizar Expo Go
En caso de que Expo Go se actualice en el celular, deberemos actualizar nuestro proyecto con los siguientes comandos

- npm install expo@^57.0.0
- npx expo install --fix
- npx expo-doctor@latest
- npx expo start --clear
